# CLAUDE.md — bogema-landing

Лендинг БогемаТур: Nuxt 4 (`frontend/`, srcDir `app/`) + Directus 11 (`directus/`, docker-compose в корне).
Карта репо и рабочий цикл — в [README.md](README.md). Ниже только правила.

## Стек и стиль
- pnpm workspace (`frontend`, `directus`). Prettier: без `;`, одинарные кавычки, 2 пробела, trailing commas.
- Компоненты автоимпортятся **без префикса папки** (`components/ui/TourCard.vue` → `<TourCard>`).
- CSS из прототипа (`tokens.css`, `landing.css`) не переписывать «под себя» — дизайн утверждён.
  Дополнения в `main.css` или scoped. Бренд: лайм `--lime`, шрифты Golos Text + Onest.
- Картинки только через `<MediaSlot>` / `useAssetUrl()`, не хардкодить `/assets/...`.

## Данные
- Главная получает всё через `useLanding()` одним `useAsyncData('landing')`. Не делать запросы в компонентах секций.
- Новое поле/коллекция = три места: Directus (сид или админка + `pnpm directus:snapshot`),
  `app/types/schema.ts`, `app/data/mock.ts`. Моки должны оставаться полным дублем прототипа —
  на них верстают, когда CMS не поднята.
- Directus — CMS лендинга, **не** источник правды по турам/ценам/местам (это `bogema-backend`).
  В `tours` лежат карточки-витрина; интеграция с бэком — отдельная задача.
- Формы пишут через `server/api/*` (серверный `$fetch` в Directus), не из браузера напрямую.

## Слои стилей
- `tokens.css` и `landing.css` — вёрстка прототипа, их НЕ переписываем.
- `motion.css` — всё движение. `refine.css` — правки дизайна поверх прототипа.
  Новая правка идёт в один из этих двух файлов, а не в landing.css.

## Моушен
- Кривые только затухающие, без bounce/elastic. Не анимировать `width`/`height`/`top`/`left`.
- Появление при скролле — только через директиву `v-reveal` (классы навешиваются в браузере,
  SSR-разметка остаётся видимой). Не гасить контент классом, который ставится на сервере.
- **Контент никогда не прячется в ожидании появления.** Базовое состояние элемента
  видимое, класс `rv-play` только запускает CSS-анимацию. Не возвращать схему, где
  элементу ставят `opacity: 0` и ждут наблюдателя: он завязан на цикл отрисовки,
  молчит в замороженной вкладке и после мгновенного перехода по якорю, и секция
  зависает пустой, а потом контент возникает рывком.
- Анимация ставится, только пока элемент ещё под кромкой экрана (`TOO_LATE`
  в `plugins/reveal.ts`). Если он уже в кадре, анимировать поздно: видимая карточка
  мигнула бы исчезновением.
- В лентах, которые прокручиваются вбок, ревил вешается на САМУ ленту в режиме `'stagger'`,
  а не на каждую карточку. Наблюдатель упирается в ленту: она обрезает укатившееся вбок,
  и карточка проявляется только когда её долистают, приезжая полупрозрачной и смещённой.
- Каждая новая анимация обязана иметь поведение в `prefers-reduced-motion`.
- Стаггер — внутри списка, не «фейд каждой секции подряд»: одинаковый ревил на всём подряд
  выглядит шаблоном.

## Directus
- Версия 11 пришпилена намеренно (лицензия/права в 12 — см. `directus/README.md`). Не поднимать без решения.
- Права публичной роли: read на контент с фильтром `status = published`, create на `subscribers`/`leads`.
- После правок схемы в админке: `pnpm directus:snapshot` → коммит `directus/schema/snapshot.yaml`.

## Проверка
- `pnpm typecheck` и `pnpm lint` должны быть зелёными перед PR.
- Вёрстку смотреть на 1320 / 1080 / 780 px — брейкпоинты из `landing.css`.
- Деплой только с явного «да» владельца (как во всех репо bogema).
